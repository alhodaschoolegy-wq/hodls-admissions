# 🏛️ منظومة مدرسة الهُدى الرسمية المتميزة للغات (H-O-D-L-S)
### بنية MVC الاحترافية — استضافة Vercel + قاعدة بيانات Supabase (PostgreSQL)

---

## 🌟 مميزات المنظومة على Vercel & Supabase
1. **قاعدة بيانات سحابية حقيقية (Supabase PostgreSQL):**
   - جدول مرئي بالكامل مثل Excel يمكنك فتحه من المتصفح والبحث والتعديل مباشرة.
   - فهارس سريعة وأمان عالي ونسخ احتياطي مجاني مدى الحياة.
2. **استضافة سحابية فائقة السرعة على Vercel:**
   - سرعة تحميل صاروخية وتوزيع جغرافي Edge Network.
   - خوادم Serverless Functions بدون أي تكلفة أو صيانة.
3. **لوحة تحكم كاملة للإدارة (Username & Password):**
   - تسجيل دخول محمي ضد التخمين (Brute-Force Rate Limiting).
   - إحصائيات، وتعديل حالات الطلاب، وطباعة الاستمارة الرسمية، وتصدير Excel فوري باللغة العربية.
4. **استمارة تسجيل ذكية متعددة الخطوات (Wizard):**
   - استخراج فوري للسن، المحافظة، والنوع بمجرد كتابة الرقم القومي للطفل (14 رقم).
   - إشعار استلام رسمي فوري قابل للطباعة (Printable PDF Slip) مزود بباركود معتمد لتقديمه للمدرسة.

## 📋 دليل التشغيل والنشر خطوة بخطوة (مجاناً 100%)

### 1️⃣ الخطوة الأولى: إنشاء قاعدة البيانات المجانية (Supabase):
1. ادخل على موقع **[supabase.com](https://supabase.com)** وسجل حساباً مجانياً (Sign up).
2. اضغط **New Project**، اختر اسماً للمشروع (مثل: `hodls-school`) وضع كلمة مرور للداتا بيز.
3. من القائمة الجانبية ادخل على **SQL Editor**، وافتح ملف `schema.sql` الموجود في هذا المشروع وانسخ محتواه والصقه هناك ثم اضغط **Run**.
   *(هذا الأمر سينشئ لك جدول `applications` والفهارس والأمان بضغطة واحدة).*
4. من القائمة الجانبية ادخل على **Project Settings** ➡️ **API**، وانسخ:
   - **Project URL**
   - **anon / service_role API Key**

---

### 2️⃣ الخطوة الثانية: رفع الموقع على Vercel:
1. ادخل على موقع **[vercel.com](https://vercel.com)** وسجل دخول بحسابك (GitHub أو Email).
2. اربط المشروع عبر GitHub أو ارفع المجلد، وفي خيارات المشروع ادخل على **Environment Variables** وأضف القيم التالية:

| اسم المتغير (Key) | القيمة (Value) | الوصف |
| :--- | :--- | :--- |
| `SUPABASE_URL` | الرابط من Supabase (مثال: `https://xyz.supabase.co`) | رابط قاعدة البيانات |
| `SUPABASE_KEY` | المفتاح من Supabase (`service_role` أو `anon`) | مفتاح الاتصال بقاعدة البيانات |
| `ADMIN_USERNAME` | `admin` (أو أي اسم تختاره) | اسم مستخدم لوحة الإدارة |
| `ADMIN_PASSWORD` | كلمة مرور قوية (مثال: `HodlsAdmin@2026!`) | كلمة مرور لوحة الإدارة |
| `SESSION_SECRET` | نص عشوائي طويل (مثال: `A786#@$lkjhf98234sdf`) | مفتاح تشفير الجلسات |

3. اضغط **Deploy**! سيعطيك Vercel رابطاً مجانياً يعمل فوراً (مثل `https://hodls-school.vercel.app`).
